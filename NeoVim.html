Neovim Cheat Sheet

For your current setup. Leader = Space. Includes project switching, responsive layout, automatic directory creation, and function jumping.

Fastest Workflow

Open Neovim anywherenvim
Pick a projectSpace f p or :Projects
Find a file in the projectSpace f f
Search text in the projectSpace f g
Open the file treeSpace e
Open the terminalSpace t

Files and Directories

CommandDoes
:e src/app.pyopen or create a file relative to the project
:wsave the file
:pwdshow the current project/root
Space eshow/hide NvimTree
a in NvimTreecreate a file or directory
components/create a directory after pressing a
components/Button.tsxcreate a file inside a new or existing directory
d in NvimTreedelete the selected file or directory
r in NvimTreerename

Autosave creates parent directories automatically when you open a new file with :e new-dir/file.txt.

Space f hhelp tags

The project picker looks for Git repos under ~/Programmering, ~/source, ~/Documents, and ~/Desktop.
